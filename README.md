# Graveyard Mash

Fight off hordes of monsters to reach high scores unseen before!
Made in custom game-engine courtesy of Visual Studio and 10 weeks of work.


## Features

- Rendering
- Texturing
- Audio
- Input
- SDL library
- JSON library 
- Tiled Software Implementation
- More!

## Controls

A - D (move left to right)
SPACE - (Jump) / (Start Game)
Right Shift (Attack)

## Known Issues

- enemy animations cut out
- infinite jump
- theme music loops on starting new game
